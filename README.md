# Mastung Water-First Rotation Advisor
Live App: https://noorulainhameed0.github.io/Mastung-Water-Advisor/

Problem: In Mastung, groundwater is falling 3-4 ft per year.

NASA Data: NASA POWER 2020-2025, Mastung 29.8N 66.84E. Soil Wetness fell from 0.54 to 0.26.

Solution: Water-First Rotation Advisor combines NASA satellite data + Karez knowledge. Farmer selects Water Source -> Soil -> Goal and gets Year 1, 2, 3 rotation plan.

Result: Saves 25-45% water, protects soil and income. Works in Urdu + English, on mobile.
